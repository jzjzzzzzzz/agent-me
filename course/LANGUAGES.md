# Course Language Coverage

[Course home](README.md) · [Localization guide](../docs/LOCALIZATION.md) · [Contributing](../CONTRIBUTING.md#translate-the-course)

Language coverage is reported explicitly so learners know whether a page is a complete reviewed
course or a project overview.

| Language | Project overview | Web interface | Full 8-lesson course | Status |
| --- | --- | --- | --- | --- |
| English | yes | yes | [yes](README.md) | canonical |
| 简体中文 (`zh-CN`) | [yes](../docs/i18n/README.zh-CN.md) | yes | [yes](translations/zh-CN/README.md) | maintained |
| 繁體中文 (`zh-TW`) | [yes](../docs/i18n/README.zh-TW.md) | yes | not yet | contributions welcome |
| 日本語 (`ja`) | [yes](../docs/i18n/README.ja.md) | yes | not yet | contributions welcome |
| 한국어 (`ko`) | [yes](../docs/i18n/README.ko.md) | yes | not yet | contributions welcome |
| Español (`es`) | [yes](../docs/i18n/README.es.md) | yes | not yet | contributions welcome |
| Français (`fr`) | [yes](../docs/i18n/README.fr.md) | yes | not yet | contributions welcome |
| Deutsch (`de`) | [yes](../docs/i18n/README.de.md) | yes | not yet | contributions welcome |
| Português do Brasil (`pt-BR`) | [yes](../docs/i18n/README.pt-BR.md) | yes | not yet | contributions welcome |

A translation is marked complete only when all syllabus, lesson, glossary, rubric, commands, links,
and navigation are present and reviewed. Machine assistance may be used, but a pull request must
state review status; unreviewed output is never labeled maintained.
